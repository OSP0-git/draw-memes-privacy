1. Приложение и размещение в RuStore

Политика действует для Android-версии игры Draw Memes. Игру размещает в RuStore Харлампьев Тимур Андреевич, физическое лицо.

2. Игровые данные

В Android-версии нет регистрации. Игра хранит прогресс на устройстве, чтобы восстановить его при следующем запуске. В сохранение входят, например, оценки за уровни, звёзды и сведения об открытых уровнях. Игра не отправляет файл прогресса или рисунки издателю либо рекламной сети.

Игра хранит прогресс до очистки данных приложения или удаления игры. Чтобы сбросить прогресс, откройте настройки Android, выберите Draw Memes в списке приложений и очистите данные приложения.

3. Реклама и данные рекламного SDK

Рекламная монетизация игры через Рекламную сеть Яндекса осуществляется ИП Харлампьевой Светланой Владимировной.

Для показа рекламы между уровнями и рекламы с вознаграждением игра использует Yandex Mobile Ads SDK и Рекламную сеть Яндекса. При запросе рекламы Яндекс получает технические сведения о подключении, включая IP-адрес. SDK может передавать рекламный идентификатор устройства, если в приложении есть соответствующее разрешение и Android предоставляет идентификатор. Передача данных о местоположении через настройки SDK в игре отключена.

Яндекс использует данные рекламных запросов для подбора, показа и оценки эффективности рекламы. Яндекс хранит полученные им данные согласно своей политике конфиденциальности. В ней описаны критерии определения сроков хранения и порядок обращения по поводу данных. Рекламный идентификатор можно сбросить или удалить в настройках рекламы Android, если эта возможность доступна на устройстве.
